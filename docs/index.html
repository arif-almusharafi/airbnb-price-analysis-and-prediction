01

The goal

Airbnb prices depend on location, room type, availability, reviews, and more. This project asks which of these matter, and how well a model can predict a fair nightly price from them. In short, the project sets out to:

  • Explore the factors linked to listing prices.
  • Find patterns across the five boroughs and the room types.
  • Prepare categorical and numerical data for machine learning.
  • Train and compare five regression models.
  • Measure them with standard regression metrics (MAE, RMSE, R²).

02

The dataset

The public AB_NYC_2019 dataset lists New York City Airbnb homes with their location, room type, nightly price, minimum stay, reviews, host listing count, and yearly availability.

  • 48,895rows and 16 columns in the original file
  • 38,821rows after removing missing values
  • 38,806rows after removing 15 extreme outliers
  • 14model features after one-hot encoding

What the models learn from

Borough, room type, latitude and longitude, minimum nights, number of reviews, the host's number of listings, and days available per year. Names, host details, and the listing id are left out because they do not describe the home.

What they predict

The nightly price in US dollars. A few listings cost up to $10,000, so the models learn log1p(price), which keeps those rare listings from dominating. The predictor turns the answer back into dollars.

03

How I worked

  1. Load and inspect the dataset. Columns, types, and first rows.
  2. Check missing values and duplicates. No duplicates; rows with missing values were dropped.
  3. Remove identifiers and non-predictive columns. Names, host details, and text dates.
  4. Explore distributions and relationships. Scatter plots, box plots, and a correlation matrix.
  5. Encode categorical features. One-hot encoding for borough and room type.
  6. Split into training and test sets. 70% to train, 30% to test, with a fixed random seed.
  7. Train multiple regression models. Linear Regression, Random Forest, K-Nearest Neighbors, Gradient Boosting, and SVR.
  8. Compare their performance. MAE, RMSE, and R² on the same test set.

        07

        Limitations

        • 2019 prices. The data is a snapshot of New York listings from 2019. Prices today are different.
        • Listed, not booked. The price is what hosts asked per night, not what guests paid.
        • A rough estimate. The best R² is around 0.6, so the model explains part of the price, not all of it. Treat the result as a starting point.
        • Missing details. Photos, size, amenities, and review text are not in the data, and they matter a lot.
        • Free hosting. The live predictor sleeps when nobody uses it and needs about a minute to wake up.
